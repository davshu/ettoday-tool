# ETtoday Canvas V15 新聞重點版型設計

## 目標

以現行 V14 為基礎新增第三種「照片＋重點文字」新聞版型，供編輯快速製作 1080 x 1350 圖卡。V14 的雜誌封面與玻璃卡版型必須維持原有輸出結果；V15 草稿先放在獨立的 `V15.html`，經人工確認後才決定是否取代 GitHub Pages 的 `index.html`。

本階段只製作前端單檔工具，不新增後端、不調整 GitHub Pages，也不推送 GitHub。

## 交付範圍

- 新增本機 `V15.html`，保留 `index.html`（V14）不變。
- 版型選單增加「版型 3：新聞三點整理」。
- 保留 V14 的本機上傳、拖曳上傳、圖片網址、多重代理、濾鏡、日期、來源、下載、複製、安全檔名及設定保存。
- 玻璃卡版型不新增欄位或功能。
- 新版型支援明亮及黑暗文字區，但不新增任意字型或裝飾特效。

## 新版型畫面

輸出畫布固定為 1080 x 1350。畫面分成上方照片區與下方文字區，提供三個安全比例：

- 照片多：55 / 45
- 平衡：45 / 55（預設）
- 文字多：35 / 65

照片只在照片區內裁切，比例切換不會改變原圖狀態。使用者可以直接拖曳照片定位，也可以沿用 V14 的縮放、X/Y 移動及濾鏡控制。

左上角分類延續 V14：快訊、房產、財經、國際、政治快速鍵、自訂分類文字及分類色。右上角公司 Logo 沿用 V14 的輸出規格：180 x 64 px、距右 50 px、距頂 80 px、圓角 32 px，並提供顯示／隱藏選項。初版維持 V14 的 Logo 呈現；取得裁切完成的透明 PNG 後只替換素材，不改動幾何規格。

## 文字編輯

主標題延續 V14 的字級控制、強制粗體及局部文字顏色。新版型的重點區改為動態清單：

- 預設三點。
- 可持續新增重點。
- 每一點可刪除。
- 每一點可用上下按鈕重新排序。
- 每一點文字可反白套用 V14 的局部顏色或清除顏色。
- 每一點使用穩定 ID 保存文字與逐字顏色；刪除或排序後顏色不得移到其他重點。

文字區提供共用內文字級控制。明亮模式使用淺色底與深色字，黑暗模式使用深色底與淺色字；新聞分類色與局部文字色不隨模式改變。

## 容量與輸出驗證

新版型不以固定「最多幾點」判斷容量，而是在 Canvas 以實際字級、換行及版面比例量測文字底部。發生以下任一狀況時，停用下載與複製並顯示原因：

- 尚未載入照片。
- 主標題或任何重點超出文字安全區。
- 來源或日期與文字區互相重疊。

系統不得為了通過檢查而把字體縮小到使用者設定值以下，也不會自動切換照片／文字比例。使用者必須精簡文字、降低字級或自行選擇文字較多的比例。

## 圖片來源與錯誤處理

本機圖片維持 V14 的檔案選擇與拖曳上傳。圖片網址維持 V14 的三組代理依序嘗試；全部失敗時顯示明確訊息，建議下載圖片後改用本機上傳。網址載入期間停用載入按鈕，成功後恢復控制。

照片拖曳與滑桿使用同一組裁切狀態，避免兩種控制彼此覆蓋。切換版型時保留背景圖片，但每個版型可有自己的裁切、縮放及文字設定。

## 狀態保存與重設

延續 V14 的瀏覽器自動保存，V15 另外保存：

- 新版型比例與明暗模式。
- 動態重點的穩定 ID、文字、順序與逐字顏色。
- 照片縮放、X/Y 位置、濾鏡。
- 分類、分類色、Logo 顯示、日期、來源與字級。

本機上傳的圖片檔案本身不承諾跨重新整理保存；重新整理後若圖片不存在，輸出會維持停用並要求重新上傳。底部「重設全部」按下後先確認，再清除設定並恢復 V15 預設三點。

## 程式結構

`V15.html` 仍維持可直接使用的單檔工具，但程式碼分成清楚區塊：

1. 常數、版型預設值及狀態模型。
2. DOM 事件與動態重點編輯器。
3. 圖片載入、裁切與代理處理。
4. Canvas 共用繪製工具。
5. V14 雜誌與玻璃卡繪製器。
6. V15 新聞重點版型繪製器與容量量測。
7. 狀態保存、重設、下載及複製。

新版型的重點資料格式為 `{ id, text, colors }`。渲染器只讀取狀態，不直接讀取動態 DOM；編輯器修改狀態後統一觸發保存、驗證及重新繪製。

## 驗證

- 比對 V14 與 V15 草稿中的版型 1、2，確認畫布尺寸、位置、字級、顏色、日期、來源及檔名行為未改變。
- 測試新版型三種比例及明亮／黑暗模式。
- 測試新增、刪除、排序重點後，文字與局部顏色仍對應正確。
- 測試照片拖曳、縮放、X/Y 滑桿及濾鏡同步。
- 測試本機圖片、圖片網址成功、代理全部失敗及 CORS 輸出錯誤。
- 測試文字溢出、無照片時下載及複製均停用。
- 測試重新整理後文字設定恢復，以及重設確認流程。
- 在桌面與手機寬度檢查控制區、預覽區及按鈕沒有重疊或裁切。

## 不在本次範圍

- GitHub 上傳或 GitHub Pages 發布。
- 後端、帳號、雲端草稿或多人協作。
- 任意高度拖曳、任意字型、陰影特效、歷史版本與復原／重做。
- Canva 檔案編輯；Canva 只在之後需要透明 Logo 素材時使用。
